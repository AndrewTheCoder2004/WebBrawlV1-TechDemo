# WebBrawlV1-TechDemo
Web Brawl V1 – Tech Demo. A lightweight, offline 3D browser recreation of the original Brawl Stars (V1 beta era). Built entirely from scratch to explore modern web-based 3D rendering, custom physics pipelines, and game engine architecture.
Overview:Web Brawl V1 is an educational proof-of-concept demonstrating real-time top-down 3D gameplay running natively in the browser without third-party game engines (no Unity, Unreal, or Godot). The core rendering and entity component architecture was authored from the ground up using GPT Astra 6 as an engineering copilot.This release focuses strictly on a faithful offline recreation of the classic Gem Grab experience.Key Features: Custom Web Engine: Built from scratch with modular systems for input polling, tick-rate synchronization, top-down orthographic camera projection, and collision resolution.Gem Grab Mode: Fully functional center-mine gem spawner, inventory gem tracking, and countdown win condition logic. Offline: Runs locally in any modern Chromium, Gecko, or WebKit browser with zero server dependencies.Preserved Aesthetics: Renders original early-era UI layouts, character meshes, and audio sequences extracted directly from preserved archive binaries.Technical Stack Component Implementation Engine Architecture Custom-built micro-engine:(engineered via GPT Astra 6)Rendering:PipelineWebGL / WebGPU rasterizer with custom cel-shading shaders. State Management Deterministic: fixed-tick loop (60 TPS)Audio: Web Audio API spatial node system Asset:Pipeline Extracted from legacy iOS IPA archives via Archive.org Asset Attribution & Provenance:All 3D models, textures, animations, and sound effects utilized in this demonstration were sourced exclusively from a publicly available, preserved iOS .ipa package of Brawl Stars V1 hosted on Archive.org. No code, reverse-engineered server logic, or private APIs from live production builds were accessed or utilized. All game logic, client networking mocks, and shaders were written independently. How to Run?
Running the tech demo is completely plug-and-play—no command line or complex setup required:

Download the latest release .zip file from the Releases section (or click Code → Download ZIP).

Extract the contents to any folder on your computer.

Double-click index.html to launch it directly in your web browser.

That's it!
